### Beam Search (`src/beam_search.py`)
```python
# Usage Example:
decoder = BeamSearchDecoder(beam_width=8, length_penalty=1.0)
output_ids = decoder.decode(encoder_outputs, initial_hidden)

# Or use SimpleBeamSearch wrapper:
decoder = SimpleBeamSearch(model, tokenizers, device='cuda')
translation = decoder.translate(akkadian_text, beam_width=8)
```

### Back-translation (`src/back_translate.py`)
```python
# Usage Example (after TIER 2 training):
generator = BackTranslationGenerator(model, tokenizers)
synthetic_pairs = generator.generate_synthetic_pairs(english_texts)
filtered = generator.filter_synthetic_pairs(synthetic_pairs, min_confidence=0.7)
generator.save_synthetic_pairs(filtered, 'data/synthetic_pairs.csv')
```
